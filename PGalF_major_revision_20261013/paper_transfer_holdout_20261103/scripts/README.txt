Reproducing the corrected manuscript diagnostics

Run commands from the `paper/` directory containing `main.tex`. The current Darwin figures use the corrected-distance tables and are regenerated with:

python scripts/plot_revised_validation.py

The artificial-redshift summary is regenerated from the combined per-view measurements with:

python scripts/summarize_artificial_redshift.py supplement/artificial_redshift_metrics_v6.tsv.gz supplement/artificial_redshift_summary.csv

The proper-size, Darwin-distance artificial-redshift runs are produced with render_artificial_redshift.py; see its command-line options and the source archive for the pinned measurement implementation. Rebuilding those measurements requires the original Darwin particle catalogues and archived FSPS grids. The script verifies native-redshift scores against the corrected-distance Darwin curves.

Archived exploratory figures can be regenerated with plot_scores.py, plot_failures.py, and plot_cluster.py. These use archived-normalization inputs and overwrite some current figures; do not use them to regenerate corrected primary plots. The archived diagnostics calibration_diagnostics.py, luminosity_diagnostics.py, and revision_diagnostics.py are documented below and do not replace the corrected primary tables.

measurement_methods.py supplies the numerical definitions of stellar flux,
stellar linking distance, pixel assignment, PSF, connected image selection,
and positional light scores. The functions were extracted from the calculation
sources recorded in calculation_config.json. The pixels function accepts the
pixel scale directly instead of importing a project global.

The boundary score uses the original image selection and restricts every light
sum to the pixel band on both sides of the boundary. For Boolean masks G, I,
and R, the intersection is G & I & R and the union is (G | I) & R. A zero
denominator produces NaN. The earlier boundary_ring.tsv compared G with R and
did not implement a score restricted to the boundary. The delivered table
replaces the earlier values with corrected measurements for all 76 entries.

To reconstruct images, provide unwrapped stellar coordinates, formed masses,
formation times, and metallicities, use the archived SSP grids, bin stellar
flux with bin_flux, and convolve with psf_kernel using fftconvolve(mode='same').
Clip negative convolution round-off to zero before applying central_isophote.
Pass stellar FoF membership as the Boolean keep array to light_scores or
boundary_scores. The central catalogue galaxy has the largest star-particle
count. Other galaxies with at least 100 star particles are removed.

source_archive supplies the production readers, image and measurement routines,
stellar FoF C sources, required project headers, and the build recipe. The source
paths retain the producing environment and require configuration elsewhere.
The particle catalogues and the compiled opFoF library are not included.
The library hash is recorded in calculation_config.json. Reproducing particle
membership requires the original inputs and a build of the stellar FoF code.
The supplied tables support reproduction of the reported statistical summaries
and inspection of the image and score definitions without the particle files.
Files prepared for this revision have not yet been added to the public deposit.

Artificial-redshift reproduction (proper-size, Darwin-distance run)
`render_artificial_redshift.py` is the exact runner used for the corrected artificial-redshift calculation. The matching measurement module is archived at source_archive/major_revision/scripts/source/sb_vs_b.py. With the original Darwin particle catalogues and the archived FSPS grids available at the paths configured in the driver, run one locked entry with `python render_artificial_redshift.py --step STEP --nstar NSTAR --tag static_population_redshift_v6_properfixed_simdistance`. Run the command for each row of inputs/halos.txt. The driver checks the native-redshift scores against the corrected-distance Darwin curves and writes the 360 per-view measurements and metadata. Summarize all completed entries with `python summarize_artificial_redshift.py RESULTS_DIR OUTPUT.csv`; the script reports equal-view detection, conditional, and operational metrics and checks their arithmetic identity. Run `python plot_revised_validation.py` to regenerate the manuscript figures. The source archive records the numerical implementation; reconstituting stellar membership still requires the original particle catalogues.

CAMELS Swift-EAGLE measurement source and metric definitions are preserved in source_archive/camels_transfer/. Its README records the pinned centered run and reproduction command.
